# 设计语言与皮肤（v2）

同一套内容，四种皮肤。皮肤只改视觉系统，不改内容结构；生成器负责把内容映射到版式。

## 共同约束

- 画布 960×540（16:9），1 px = 1 pt。
- 版心：左右 56；页眉线 y=78；正文可用 96–452；页脚 y=512；页码 y=486 右对齐。
- 标题字号 26–30，正文 16–18，注释 13，图注 11，页脚 8.5。
- 中文用 `Microsoft YaHei`（Windows）/ 系统黑体回落；英文与数字用 Arial；公式 Times New Roman；页脚小字 Georgia。
- 留白优先：正文每段 1–2 行；宁可少放一条，不把页面填满。
- 每页最多 4 个要点、2 个视觉重点；论文图按原比例，不拉伸。

## 1. academic（学术 · 院系格式，默认）

- 白底；左上校徽（56,18,190×43.5），右侧编号标题 26 号加粗，标题下 1 px 细线（品牌色 30% 灰）。
- 页脚：左 motto（品牌色 80% 灰，8.5 号，字距 0.5），右学院英文名，右下页码。
- 正文：黑 `#1A1A1A`；小标题 17 号加粗；图注 11 号灰；论文来源 8 号灰。
- 章节页：白底，左上大数字（品牌色，72 号，半透明），右侧章节标题 + 本节 3–4 条预告。
- 关键数字页：白底，数字 44 号品牌色，说明 13 号灰，细线分隔。
- 适用：组会文献汇报、开题/中期、答辩、学院格式任务。
- 参考：`assets/college_crest.png` 那套（示例大学示例学院）。

## 2. campus（校园 · 课程汇报）

- 封面：品牌色大色块（左 40% 或顶 30%）+ 反白大标题 + 校徽；右下院徽/日期。
- 页眉：品牌色细条（顶部 6 px）+ 校徽小图（左 44×20）+ 标题 24 号；没有页眉线，留白多一点。
- 正文：左侧 3 px 品牌竖条引出要点；要点用圆点编号；关键词用 `soft` 底色块 highlight。
- 章节页：整页品牌色底，反白大数字 + 标题 + 3 条预告。
- 关键数字页：3 个浅灰卡片，数字 40 号品牌色。
- 适用：个人课程汇报、读书报告、课堂展示。

## 3. modern（现代 · 组会进展）

- 无页眉框；左上 8.5 号眉标（字母间距 1.2，灰），下面是结论式大标题（28 号，近黑）。
- 正文：细线条目（上边 1 px 浅灰）+ 关键词加粗；每页 3–4 条，行距大；底部一条 1 px 品牌色短线。
- 封面：白底 + 品牌色细线 + 大标题 + 右下信息块；没有大色块。
- 章节页：白底，超大浅灰数字（120 号，10% 透明度）+ 标题。
- 适用：组会进展汇报、论文进展、阶段总结。

## 4. bold（撞色 · 项目/竞赛）

- 封面：深色底（`deep`）+ 品牌色几何色块 + 大白字标题。
- 页眉：深色条 + 反白标题；正文白底，左侧 8 px 品牌粗条 + 无衬线大字。
- 章节页：整页 `primary`，反白数字与标题，金色点缀。
- 关键数字页：品牌色底白字大数字。
- 适用：项目/竞赛汇报、宣传材料。

## 皮肤选择建议

| purpose | 默认皮肤 |
|---|---|
| `group_paper`（组会文献） | `academic` |
| `proposal` / `defense`（开题、答辩） | `academic` |
| `course_report`（课程汇报） | `campus` |
| `group_progress`（组会进展） | `modern` |
| `project`（项目/竞赛） | `bold` |

用户在向导里可以覆盖。生成器遇到未实现的皮肤名，回落到 `academic` 并打印提示。

## 动画（motion）

| 档位 | 转场 | 元素动画（PPT 工具链模式） |
|---|---|---|
| `none` | fade | 无 |
| `gentle` | fade | 封面标题 fade-in；正文每个要点块 fade-in（afterPrevious，依次）；图 zoom-in |
| `lively` | auto（引擎混合 fade/push/wipe） | 封面标题 fly-in；要点 fly-in；章节页数字 zoom-in |

- 每页最多 3 组动画；同一元素不连续加多个强调。
- 打印/发送版用 `none`；本地 python-pptx 兜底导出只写转场，不写入元素动画（文件里会注明）。
